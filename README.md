# 사다리 게임
## 진행 방법
* 사다리 게임 게임 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

# step 2. 사다리(생성)

## 요구사항

### 기능 요구사항

- 사다리 게임 참여하는 사람 이름은 최대 5글자
- 사다리 출력 시 사람 이름도 같이 출력 가능
  - 사람이름 쉼표(,) 로 구분
  - 사람 이름 5자 기준으로 출력하므로 사다리 폭도 넓어 져야함
  - 사라리 라인이 안겹치게 해야함
    - 가로로 겸쳐지는 경우 어느방향으로 이동할지 결정 불가

### 프로그래밍 요구사항

- 스트림, 람다 적용 / 규칙 6 : 모든 엔티티 작게 유지

## 객체 설계

### 객체 역할

- Participant : 사다리 게임 참석자 (이름, 현재위치)
- Participants : 사다리 게임 참석자들
- Ladder : 사다리
  - Line : 사다리 폭
    - 참가자의 수 만큼 생긴다
  - Height : 사다리 높이 (제네릭으로 구현)
  - 사다리의 정책
    1. 이미 선이 있는지 없는지 검증한다
    2. 가로선은 50:50 존재하거나 존재하지 않는다

### 구현 순서

participant → ladder → Line → height → participants

### 객체별 주요 구현 사항

#### participant

- [x] : 참가자 이름

#### ladder

- [x] : 사다리에 가로 선 만들기
- [ ] : 사다리의 높이와 폭 정보
- [ ] : 높이는 직접 입력, 폭은 이름으로 벌리기

#### participants

- [ ] : 참석자들의 수
